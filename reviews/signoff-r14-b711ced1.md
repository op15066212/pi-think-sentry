
## 二、问二：你问我要哪种——我实测了，答案是**都不加**

你问「设 len 门槛」还是「按 len 分两类分别处理」。我按第二种写了个判据（短块「去掉重复行后剩余字符 < 20」按 3 判，其余按 4），

```
块=1138   A(全局 min3)=167   B(全局 min4)=61   C(短3长4)=61   D(同上)=61
```

**C 与 B 完全相等。** 在这份会话上，「短块按 3」一次都没多拦——因为这里的 reps=3 全部落在长块里，

如果 6e8dd769 认为那 101 次必须拦，正确的做法是他那条判据（短块阈值）落在他那份数据上，不是叠在我的上面。
