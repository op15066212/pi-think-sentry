新注释（`test/deadlock.test.ts:24`）写的是：

```

「两两不同」那半句你改对了。但**这条防线不覆盖它自己声明的对象**，原因是计数口径：

```
src/judges.ts:432  const chars = vs.reduce((n, l) => n + new Set(l.t).size, 0);

所以「凑不出 24 种字符」这句与代码不是一回事：代码数的是「每行各有多少种字符，再加起来」，跨行重复的字符被**重复计数**。两行结构相同的中文（「这一段的结论是甲」/「这一段的答案是乙」）就能把它喂满。
