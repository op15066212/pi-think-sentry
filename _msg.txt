判据二第三次重构：从「匹配形状」改成「测结构性质」

退化被绕过两次，两次都是我按形状写判据：

  v1 dup      按整行计数        → 模型把重复压进一行（ok。ok。ok。…）      漏
  v2 inline   按句找「连续相同」 → 模型换成交替（跑。ok。跑。ok。）          漏
                                 和「换词不换结构」（执行。ok。/ 好。执行。ok。）漏

v3（本次）不再认形状，测结构：

  Γ ⊢ 段 : Seg = Sentence*          按行切，行内再按 。！？!? 切
  W ⊂ Seg                           任意连续区间
  uniq(W) = |{ s ∈ W }|
  坍缩(W) ⟺ uniq(W)/|W| ≤ 1/4  ∧  |W| ≥ 12
  判红 ⟺ 存在坍缩区间

前两版是它的特例：连续 37 句 uniq=1、交替 AB uniq=2、换词不换结构 480 句 uniq≈10。
三条真实形状在同一条判据下全红（实测 23 段真退化全中，5 条正常文本零误判）。

同一次重构要修的四件事：

1 Verdict 改成依赖和类型
  旧：kind×rule 两条正交轴，strip×lang 这类组合靠 parse 的 if 链在运行时挡。
  新：Verdict = Σ(k : Kind). EvOf(k)，RuleOf : Kind → Set Rule。
      「strip 配 inline」在类型里不存在——不是检查出来的，是写不出来。
      fold 独立成构造子：处置是「行内折叠」，与 strip 的「整行删除」是两个动作。
      消费点用 switch + assertNever：加构造子漏改一处 → tsc 报错。

2 区间两端收缩
  只取「最长区间」会把紧挨着的正常句一起折掉（只要加进来比例仍达标）。
  修：首/尾若在区间内只出现一次，就还给原文。

3 折叠按行区间，不按句子正则
  用第一句做正则会误删区间外同句、区间内其余行原样留着——等于没治。
  现在按 ev.line..ev.lineTo 整段替换成一行标记，区间前后内容保留。实测 1410→142 字节。

4 注入文案不计入坍缩
  否则「判红 → 注入提醒 → 提醒被当成重复 → 再判红」自锁（wiring.test 正是抓这个）。

配套：
- features/inline.ts：配置单元（on/min），与 dup.ts 同形，注册进 MODULES
- defaults.inject.texts.inline：句内重复用独立文案，不说「第几行重复」以免引向删行
- test/collapse.test.ts：11 条（3 退化形状必红、4 正常文本不误判、区间定位、折叠、
  非法组合 parse 必须抛、穷尽性）
